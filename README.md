# Hannah Yiu - Personal Portfolio

A clean, responsive personal portfolio website for Hannah Yiu, a Bay Area based web developer with a background in Linguistics and a passion for design.

## 🌟 About

This is Hannah's personal portfolio website showcasing her professional profile as a developer, doodler, and dreamer. The site features a minimalist design that highlights her background in full-stack development with a focus on front-end work.

## 🚀 Features

- **Responsive Design**: Mobile-first approach with responsive breakpoints
- **Clean UI**: Minimalist design with elegant typography using Google Fonts
- **Social Integration**: Links to professional and creative profiles
- **Performance Optimized**: Lightweight HTML/CSS implementation
- **Analytics**: Google Analytics integration for visitor tracking

## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with flexbox and media queries
- **Google Fonts**: Enriqueta and Raleway font families
- **Font Awesome**: Social media icons (v4.7.0)
- **Google Analytics**: Visitor tracking and analytics

## 📱 Responsive Design

The website is fully responsive with breakpoints for:
- Desktop (default)
- Medium devices (≤880px)
- Small phones (≤370px)
- Extra small devices (≤300px)

## 🎨 Design Elements

- Circular profile image with subtle shadow effects
- Fixed footer with social media links
- Hover effects on interactive elements
- Color scheme featuring pink accent (#D2186D) on neutral background
